## A famosa calculadora financeira

A **HP-12C** é uma calculadora financeira programável que utiliza a **notação polonesa reversa (RPN)**. Por isso, a forma de digitar expressões é diferente da notação algébrica tradicional.

É possível encontrar um emulador online aqui **[HP-12C](https://simulado.estacio.br/img/Hp/)**, ou ainda baixar a versão mobile na Play Store: [Touch RPN](https://play.google.com/store/apps/details?id=co.epxx.touch12if&hl=pt_BR).

## Notação Polonesa Reversa (**RPN**)
A notação polonesa reversa (_RPN_) é uma lógica que pode ser utilizada para o tratamento das expressões aritméticas em linguagem de programação e que funciona, especialmente, para o processamento de dados oriundos dos cálculos financeiros. Sua vantagem frente ao sistema de notação tradicional se dá em (considerando 1981 que foi o ano de lançamento): otimização de memória e hardware, eficiência de teclas (menos toques) e resolução em tempo real sem precisar usar papel para anotar resultados intermediários. 

### Pilhas
A HP-12C possui quatro pilhas (registradores) ou “caixinhas” para dados: $\mathbf{X}$, que é o dado que fica exposto no visor, além das “caixinhas”: $\mathbf{Y}$, $\mathbf{Z}$, e $\mathbf{T}$, que ficam ocultas. Os dados vão sendo armazenados ou “empilhados” nas “caixinhas”, para serem processados posteriormente aos seus lançamentos.

Sendo assim, toda vez que a tecla enter é pressionada, então na realidade estamos guardando um número nessa pilha. Por isso só é possível apertar 4 vezes a tecla enter, depois disso, a inserção de novos dados acarreta na perca dos antigos. 

| **Registrador** | **Nome**           | **Função**                                                                     |
| --------------- | ------------------ | ------------------------------------------------------------------------------ |
| **$T$**         | _Top_ (Topo)       | Quarto nível. Retém o valor superior para reutilização em operações em cadeia. |
| **$Z$**         | _Third_ (Terceiro) | Terceiro nível. Desce para $Y$ à medida que você faz operações.                |
| **$Y$**         | _Second_ (Segundo) | Segundo nível. É o operando secundário nas operações.                          |
| **$X$**         | _Display_ (Visor)  | O valor atualmente visível e no qual você está digitando.                      |
|                 |                    |                                                                                |

### Tecla <kbd>R⬇</kbd> (Roll Down)
A tecla <kbd>R⬇</kbd> funciona como um carrossel: a cada clique, ela rotaciona os valores da pilha para baixo. O valor de **Y** desce para o visor (**X**), **Z** vai para **Y**, **T** vai para **Z** e o valor do visor (**X**) vai para o topo (**T**).

#### O Truque dos 4 Cliques
Como a pilha tem 4 posições, você pode espiar tudo e voltar ao início sem alterar nenhum dado:

- **1º clique:** Mostra o registrador **Y**
- **2º clique:** Mostra o registrador **Z**
- **3º clique:** Mostra o registrador **T**
- **4º clique:** Volta ao registrador **X** original

### Comandos básicos
#### Número de casas decimais
É possível alterar o número de casas decimais exibidas por meio da combinação de teclas <kbd>f</kbd>  <kbd>número</kbd>. Exemplo: se eu quiser exibir duas casas decimais, eu posso teclar <kbd>f</kbd>  <kbd>2</kbd>.

#### Limpar visor
Para apagar o número exibido no visor (registrador X), utilize a tecla <kbd>CLx</kbd>.

#### Limpar todos os registradores
Para zerar todos os registradores, a pilha e qualquer operação em andamento, pressione <kbd>f</kbd> <kbd>REG</kbd>.

#### Corrigir um dígito digitado
Caso tenha digitado um número errado, é possível apagar o último caractere do visor — da direita para a esquerda — pressionando <kbd>g</kbd> <kbd>←</kbd> (função secundária indicada pela seta ← na tecla de subtração <kbd>$-$</kbd>).

#### Inverter o sinal de um número
Para trocar o sinal (positivo/negativo) do valor exibido no visor, pressione <kbd>CHS</kbd> (*Change Sign*). A tecla converte o número atual do registrador **X** para seu valor oposto. 

#### Convenção de dias da semana

A HP-12C codifica os dias da semana conforme a tabela abaixo:

| Número | Dia da Semana |
| :----: | :-----------: |
|   1    | Segunda-feira |
|   2    |  Terça-feira  |
|   3    | Quarta-feira  |
|   4    | Quinta-feira  |
|   5    |  Sexta-feira  |
|   6    |    Sábado     |
|   7    |    Domingo    |

#### Exercício 13

**(A)** Uma pessoa foi a um supermercado e comprou $18$ latas de conserva a $0{,}85$ UM cada, $36$ quilos de arroz a $0{,}75$ o quilo e $8$ quilos de feijão a $0{,}95$ UM o quilo. Quanto gastou esta pessoa?

**(B)** Suponha que tenha ocorrido um engano e que o preço do arroz não seja $0{,}75$ UM e sim $1{,}10$ UM. Se os dados estão contidos na calculadora, é possível corrigir os cálculos. Quanto ficou o valor total?

<details markdown="1" class="details-animated">
<summary><strong>Ver resposta</strong></summary>

**Resolução na HP-12C:**

Neste tipo de problema, queremos multiplicar a **quantidade** pelo **preço** de vários itens e somar tudo no final:

\\[\text{Total} = (18 \\times 0{,}85) + (36 \\times 0{,}75) + (8 \\times 0{,}95)\\]

A HP-12C faz essa conta acumulada automaticamente usando a **memória estatística** (Σ+).

Quando você digita a quantidade, aperta <kbd>ENTER</kbd>, digita o preço e aperta <kbd>g</kbd> <kbd>Σ+</kbd>, a calculadora faz duas coisas:

1. Multiplica a quantidade pelo preço.
2. Guarda esse resultado acumulado na memória interna **R6** (registrador de somatório \\(xy\\)).

---

**Parte (A): Calculando o valor gasto inicial**

**Passo 1: Limpar a memória estatística**

Antes de começar qualquer conta acumulada, limpe os registros antigos com <kbd>f</kbd> <kbd>Σ</kbd> (função secundária <kbd>CLEAR Σ</kbd>).

**Passo 2: Inserir as latas de conserva (18 unidades a 0,85 UM)**

| Teclas na HP-12C                                              | Visor Esperado |
| :------------------------------------------------------------ | :------------- |
| <kbd>18</kbd> <kbd>ENTER</kbd> <kbd>0.85</kbd>  <kbd>Σ+</kbd> | $1.00$         |

> O visor mostra \\(1.00\\), indicando que o **1º item** foi registrado. A HP-12C acumulou \\(18 \\times 0{,}85 = 15{,}30\\) no registrador R6.

**Passo 3: Inserir o arroz (36 kg a 0,75 UM)**

| Teclas na HP-12C                                              | Visor Esperado |
| :------------------------------------------------------------ | :------------- |
| <kbd>36</kbd> <kbd>ENTER</kbd> <kbd>0.75</kbd>  <kbd>Σ+</kbd> | $2.00$         |

> O visor mostra \\(2.00\\), indicando que o **2º item** foi registrado. A HP-12C somou \\(36 \\times 0{,}75 = 27{,}00\\) ao acumulado.

**Passo 4: Inserir o feijão (8 kg a 0,95 UM)**

| Teclas na HP-12C                                             | Visor Esperado |
| :----------------------------------------------------------- | :------------- |
| <kbd>8</kbd> <kbd>ENTER</kbd> <kbd>0.95</kbd>  <kbd>Σ+</kbd> | $3.00$         |

> O visor mostra \\(3.00\\), indicando que o **3º item** foi registrado. A HP-12C somou \\(8 \\times 0{,}95 = 7{,}60\\) ao acumulado.

**Passo 5: Ver o total gasto**

| Teclas na HP-12C            | Visor Esperado |
| :-------------------------- | :------------- |
| <kbd>RCL</kbd> <kbd>6</kbd> | $49.90$        |

> Como a HP-12C acumula a soma dessas multiplicações no registrador de memória número 6, basta chamar esse valor na tela com <kbd>RCL</kbd> <kbd>6</kbd>.
> A pessoa gastou **\\(49{,}90\\) UM**.

---

**Parte (B): Corrigindo o preço do arroz (de 0,75 para 1,10 UM)**

Como os dados já estão salvos na memória da calculadora, não é necessário refazer tudo do zero. Usamos a função <kbd>g</kbd> <kbd>Σ−</kbd> para subtrair o valor errado e inserimos o correto.

**Passo 1: Retirar o lançamento errado do arroz (36 kg a 0,75 UM)**

| Teclas na HP-12C                                                          | Visor Esperado |
| :------------------------------------------------------------------------ | :------------- |
| <kbd>36</kbd> <kbd>ENTER</kbd> <kbd>0.75</kbd> <kbd>g</kbd> <kbd>Σ−</kbd> | $2.00$         |

> Isso remove a conta antiga do arroz da memória. O visor volta a \\(2.00\\) (dois itens registrados).

**Passo 2: Inserir o lançamento correto do arroz (36 kg a 1,10 UM)**

| Teclas na HP-12C                                              | Visor Esperado |
| :------------------------------------------------------------ | :------------- |
| <kbd>36</kbd> <kbd>ENTER</kbd> <kbd>1.10</kbd>  <kbd>Σ+</kbd> | $3.00$         |

> Isso adiciona o novo valor do arroz na memória. O visor volta a \\(3.00\\).

**Passo 3: Ver o novo total corrigido**

| Teclas na HP-12C            | Visor Esperado |
| :-------------------------- | :------------- |
| <kbd>RCL</kbd> <kbd>6</kbd> | $62.50$        |

> O valor total corrigido ficou em **\\(62{,}50\\) UM**.

</details>

<script>
(function() {
  function animate(details, shouldOpen) {
    const summary = details.querySelector('summary');
    const items = Array.from(details.children).filter(c => c !== summary);

    if (shouldOpen) {
      details.setAttribute('open', '');
      const fullH = details.scrollHeight;
      details.style.overflow = 'hidden';
      details.style.maxHeight = summary.offsetHeight + 'px';
      requestAnimationFrame(function() {
        requestAnimationFrame(function() {
          details.style.transition = 'max-height 0.35s cubic-bezier(0.4, 0, 0.2, 1)';
          details.style.maxHeight = fullH + 'px';
          details.classList.add('is-open');
        });
      });
      setTimeout(function() {
        details.style.maxHeight = '';
        details.style.overflow = '';
        details.style.transition = '';
      }, 350);
    } else {
      const currH = details.scrollHeight;
      details.style.overflow = 'hidden';
      details.style.maxHeight = currH + 'px';
      details.classList.remove('is-open');
      requestAnimationFrame(function() {
        requestAnimationFrame(function() {
          details.style.transition = 'max-height 0.3s cubic-bezier(0.4, 0, 0.2, 1)';
          details.style.maxHeight = summary.offsetHeight + 'px';
        });
      });
      setTimeout(function() {
        details.removeAttribute('open');
        details.style.maxHeight = '';
        details.style.overflow = '';
        details.style.transition = '';
      }, 300);
    }
  }

  document.addEventListener('DOMContentLoaded', function() {
    document.querySelectorAll('.details-animated').forEach(function(d) {
      var s = d.querySelector('summary');
      if (!s) return;
      s.addEventListener('click', function(e) {
        e.preventDefault();
        animate(d, !d.hasAttribute('open'));
      });
    });
  });
})();
